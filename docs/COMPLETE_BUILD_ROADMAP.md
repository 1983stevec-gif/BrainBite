## Program Rules

- Preserve the existing static HTML/CSS/classic `app.js` plus Three.js/WebGL PWA, LearningCore, profile boundaries,
  reward ledger, save/recovery and DOM fallback. Do not create duplicate systems.
- The orchestrator owns architecture, priorities, integration, visual direction,
  acceptance and truth in the control plane.
- Bounded easy inventory, extraction and pattern-following work goes to Luna.
- The requested Astra visual-worker routing cannot be used under the active
  deployment policy. Until that policy changes, the orchestrator retains visual
  direction and uses only permitted bounded specialists with independent review.
- No vendor keys, paid generations, cloud changes, publishing, commits or pushes
  are implicit in this roadmap. Each external action needs its own authority/gate.
- Every substantive implementation phase closes with focused tests, independent
  review and the full release gate. Physical/human/external gates are never inferred.

## Phase 3.1/3.2 Gate Note

The Phase 3.1 implementation gate is complete. One canonical per-profile LearningCore
owns adaptive curriculum, homework assisted-vs-independent evidence, parent
intelligence, profile isolation, recovery, offline queue, exact cloud merge, cross-tab
persistence, v5 compact provenance, BrainBite Lab, and all three activity-family core
state machines.

v5 retains exact per-writer identity, sequence, and category totals in a compact
Firestore-safe scalar. It fails closed at `8192` writers or `480 KiB`; no lossy
compaction occurs within the supported ceiling. Browser lock coverage includes Web
Locks, IndexedDB, and a localStorage-only generation-verified fallback.

Final verification is `95/95` unit, `89/89` browser, all `9` validators, and an
independent final reviewer `PASS`. These are automated/review results, not runtime,

update.

## Definition Of Complete

BrainBite is complete only when all non-external phases have passing evidence,
all required external gates are signed or explicitly removed from product scope,
the production artifact passes clean-install and supported-device tests, and no
reproducible P0 remains. A green browser suite or attractive screenshot alone is
not 100% product completion.
