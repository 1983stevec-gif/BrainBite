# BrainBite v1.3 Playtest Optimization

## New tuning controls
- Calm / Balanced / Arcade movement feel
- Coach / Classic / Gentle wrong-answer response
- Auto-assist after two consecutive misses
- Per-session recap: accuracy, max combo, moves, duration

## Recommended family default
Balanced movement + Coach response + Auto-assist on.

## Playtest rule
Tune first. Add features only when repeated sessions show the same unmet need.
