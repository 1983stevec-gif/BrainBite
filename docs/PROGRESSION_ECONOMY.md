# BrainBite Progression Economy v1.1

## XP
- normal mission: +20 XP
- boss mission: +40 XP
- level threshold: current level × 100 XP

## Spark
- normal mission: +5
- boss mission: +15
- Memory Drop launch: +3

Spark is a non-paid progression currency for future cosmetics and den decoration.

## Design rule
No pay-to-win items, no loot boxes, and no child-directed pressure to purchase.
