# BrainBite Launch Alpha Privacy & Parent Controls

This build is designed for family playtesting.

## Child-facing defaults
- no public child profile
- no open chat
- no stranger messaging
- no public matchmaking
- no location sharing
- no targeted advertising
- no social follower system
- profile data remains local in this build

## Parent-controlled areas
- profile creation
- Snap-to-Game worksheet intake
- custom practice requests
- notifications (future)
- cloud sync (future)

## Data minimization
The prototype stores only gameplay state needed for progress:
- profile name
- mission progress
- mastery estimates
- mistake history
- Bite collection
- reviewed practice requests

This file is product guidance, not a legal privacy policy.
