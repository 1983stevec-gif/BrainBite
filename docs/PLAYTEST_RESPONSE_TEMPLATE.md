# BrainBite v1.2 Playtest Response Template

For every family session, capture:

## Session
- tester age
- device
- world chosen first
- session length
- replayed mission?
- favorite Bite?
- quit point

## Observed friction
- onboarding confusion
- movement confusion
- target-reading confusion
- enemy frustration
- wrong-answer frustration
- parent dashboard confusion
- install/offline issue

## Decision
Classify each note:
- keep
- tune
- fix
- remove
- investigate

Do not add a major new feature in response to one isolated comment unless the same need appears repeatedly.
