# BrainBite v12 Final Release Runbook

## Automated
1. npm install
2. npx playwright install
3. npm run release:check

## Firebase
1. Create dedicated Firebase project.
2. Enable Email/Password Authentication.
3. Create Firestore.
4. Deploy `firebase/firestore.rules`.
5. Add Project ID + Web API key in Integrations.
6. Create parent account.
7. Push cloud data.
8. Sign in on a second browser/device.
9. Pull cloud data and verify profile isolation.
