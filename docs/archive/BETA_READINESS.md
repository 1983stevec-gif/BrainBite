# BrainBite v1.1 Beta Readiness

## Beta goals
- validate fun before expanding scope
- validate learning comprehension
- confirm parents understand mastery and practice creation
- test PWA install/offline reliability
- collect device/browser issues
- verify profiles and saves are robust

## Beta success signals
- child can start playing without adult explanation
- child voluntarily replays at least one mission
- child understands correct vs incorrect CHOMP targets
- parent understands what skill is improving
- no critical save-loss bugs
- no blocker on touch controls
- offline reload works after first load
