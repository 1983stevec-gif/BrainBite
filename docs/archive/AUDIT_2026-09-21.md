### Additional changes made while executing

- `presentation/gltf-assets.mjs` rewritten: parse cache, clone-on-mount, detach-only
  dispose, plus read-only `window.BrainBiteGltfCache` diagnostics (`size`, `clones`).
- `vendor/three/addons/utils/SkeletonUtils.js` vendored from the installed three 0.170.0
  so rigged cloning stays offline-safe.
- Service worker precaches `fonts.css`, both font files, `sw-register.js`, and
  `SkeletonUtils.js`; cache name is now `brainbite-v2.0-shell-v38-first-run-gltf-cache`.
- `scripts/self-host-fonts.mjs` added with `npm run fonts:self-host` so the font
  pipeline is reproducible.
- `scripts/check-dead-css.mjs` added with `npm run check:css` (read-only; `--strict`
  exits non-zero). It parses selector preludes only, so `#rrggbb` colours in declaration
  values are not mistaken for id selectors. Current result: 255 class and 21 id
  selectors, none dead.
- Dead-CSS removal used a minimal CSS walker (comments, nested at-rule blocks, and
  multi-line selector lists preserved) with two guards: it aborts on any brace-balance
  change or if more than a third of the stylesheet would disappear. A selector is dead
  when it names a class or id that no element can carry, even if it also names a live
  ancestor — which is what removed the `.battle-target .mm-chest` style of rule.
- **Fixed the last known flake.** `same-installation tabs use distinct bounded
  provenance writers` read back `.recentPerformance.at(-1)`, but cross-tab sync can
  merge the sibling tab's attempt into this store first, so a tab could read the other
  tab's record and see two identical writer ids. The test now reads back its own attempt
  by identity. Verified with `--repeat-each=4`: `4/4` pass.
