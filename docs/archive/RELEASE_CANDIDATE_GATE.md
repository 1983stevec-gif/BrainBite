# BrainBite v1.4 Release Candidate Gate

## Required before public beta
- Zero P0 save-loss or startup bugs
- Touch and keyboard gameplay verified
- PWA install/offline verified on supported browsers
- Profile separation verified
- Reduced-motion and high-contrast checked
- Parent-facing Snap/Practice flows reviewed
- Curriculum claims kept conservative until educator validation
- Privacy/terms reviewed before collecting cloud child data
- Family playtest feedback triaged

## Go / No-Go
Public beta is GO only when all P0/P1 issues from the test cohort are closed.
