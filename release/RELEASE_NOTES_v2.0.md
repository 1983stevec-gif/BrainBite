# BrainBite v2.0 — Release Notes

BrainBite v2.0 is the first feature-complete production-ready build candidate.

## Core experience
- CHOMP-based arcade learning
- Number Nebula, Wordwood, and Language Portals
- bosses, combos, Super Bite, Mistake Monsters, Concept Morph
- family profiles and Bite collection
- Parent Dashboard, Practice Lab, Snap-to-Game reviewed intake
- Memory Drops and Mistake DNA
- Learning Insights and adaptive next-skill suggestions
- Bite Shop with cosmetic-only Spark rewards

## Content
- K–6 curriculum architecture
- Spanish, French, German, Italian, Japanese starter packs
- deeper Math and Words question banks
- content integrity validator

## Platform
- installable PWA
- offline shell
- keyboard/touch controls
- save migration, backup, recovery, export/import
- accessibility options
- original BrainBite SVG character/world art
- GitHub CI/test scaffolding

## Important
Mastery values are product estimates, not formal assessments.
Curriculum and language packs require appropriate human review before making educational claims.
