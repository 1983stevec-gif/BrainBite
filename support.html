BrainBite Support

Use this page for family support, account recovery guidance, and launch-time issue reporting.

How To Get Help

  • Open Diagnostics inside BrainBite before resetting local data.
  • Use the parent-authorized progress export before any reset or uninstall.
  • Store recovery exports privately. They may include local legacy practice records that are never sent through cloud sync.
  • Include the device, browser, profile name, and exact time when reporting a problem.
  • Attach a screenshot if the issue is visual or if a prompt is unclear.

What Support Needs To Know

  • Whether the issue happened online or offline.
  • Whether the child profile was being used or the parent dashboard.
  • Whether the problem involved save recovery, sync, accessibility, or a mission.
  • Whether the issue can be reproduced after a reload.

Interim Contact (pre-production)

Until the production support email is confirmed, report launch blockers via GitHub Issues for BrainBite. Replace this with the final public support channel before external launch.
